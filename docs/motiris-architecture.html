motiris — Iris as a mote 架构图

150KB 单二进制 · C11 · libcurl.so.4 唯一运行时依赖 · 本轮改造:REPL 增强 / 会话回顾 / Skill 编辑

入口层

  • CLI / REPL / HTTP 网关 / cron 四个入口共用同一 agent 循环
  • REPL 新增:/sessions /resume /skills + 自动会话日志

核心 + 工具层

  • agent 循环:model → tool_calls → execute → result
  • tools 注册表 ≤128:内置/文件/网络/记忆/技能/子代理/浏览器/MCP/插件

存储层

  • 会话日志统一走 sessions.c(U/A/T 行,网关与 REPL 同格式)
  • skill 编辑工具仅作用于 --skill-dir 索引内文件
